## Что реализовано

**Методы сравнения текстов:**
- **TF-IDF** — разреженные частотные векторы с биграммами, косинусная близость
- **LSA** (латентный семантический анализ) — снижение размерности через SVD (степенная итерация), улавливает скрытые темы
- **Гибрид** — взвешенная комбинация TF-IDF и LSA (параметр Alpha)
- **Нейросеть** — модель `all-MiniLM-L6-v2` через Transformers.js; понимает смысл, а не только слова

**Функциональность:**
- Список рекомендаций с оценкой сходства (score)
- Вкладка сравнения: все 4 метода рядом — видно как разные подходы дают разные результаты
- Граф связей между заметками (SVG)
- Метрики качества: Precision@K, Recall@K, NDCG@K
- Загрузка собственных заметок: отдельные файлы `.txt`/`.md` или целая папка

## Как запустить

### TF-IDF / LSA / Гибрид — без сервера

Двойной клик на `index.html`. Работает сразу, без интернета.

### Нейросеть — через локальный сервер

```
start.bat
```

Скрипт автоматически проверяет наличие модели. Если модель не найдена — загружает её.  
После запуска откроется `http://localhost:8080`. Нажать «Запустить нейросеть» в панели параметров.

### Вручную

Если модели ещё нет — можно скачать вручную:

```bash
python download_model.py
```

Затем запустить сервер:

```bash
python -m http.server 8080
# открыть http://localhost:8080
```

```
semantic-notes-recommender/
├── index.html          # визуал
```

## Как пользоваться

1. Нажмите **«Пример»** — загрузятся 16 встроенных заметок на темы NLP и кибербезопасности
2. Выберите заметку в списке слева
3. Вкладка **«Рекомендации»** — топ похожих заметок по выбранному методу
4. Вкладка **«Сравнение»** — все 4 метода рядом
5. Вкладка **«Граф»** — визуализация сети связей
6. Вкладка **«Метрики»** — Precision@K, Recall@K, NDCG@K для каждого метода
7. Для нейросети: выберите метод **«Нейросеть»** → нажмите кнопку «Загрузить нейросеть» в панели параметров
