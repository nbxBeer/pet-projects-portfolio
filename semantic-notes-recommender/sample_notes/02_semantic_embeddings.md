# Семантические эмбеддинги

Sentence embeddings позволяют переводить текст в плотные векторные представления.
Близкие по смыслу тексты располагаются рядом в векторном пространстве.

Такие модели хорошо работают для semantic search и recommendation systems.
Даже если заметки используют разные слова, embeddings могут определить смысловую связь.
