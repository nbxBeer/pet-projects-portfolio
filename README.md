## Знакомство с проектами

- Описание и инструкции каждого проекта находятся в его README.
- В ribal основной код лежит в `fishbot/`: команды из README следует выполнять из этой папки.
- MCP-интеграция StarLoot отдельно описана в [StarLoot/admin-panel/mcp/README.md](StarLoot/admin-panel/mcp/README.md).
- Примеры конфигурации используют только демонстрационные значения. Для запуска нужны собственные настройки и учётные данные.

Старые коммиты исходных репозиториев сюда не перенесены.
Из копий исключены Telegram-сессии, рабочие файлы окружения, базы данных,
локальные настройки ИИ-инструментов, установленные зависимости, сборки,
личные фотографии, профильные тексты и экспериментальные вспомогательные файлы.
Исходные README сохранены с точечными заменами учётных данных и локальных путей на примеры.
Фотографии и профильные тексты FishBot можно добавить локально при необходимости.
