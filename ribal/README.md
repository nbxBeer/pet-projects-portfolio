# 🐟 FishBot

Веб-приложение для автоматической отправки сообщений в Telegram-группу по расписанию.
Поддерживает несколько аккаунтов, гибкий jitter-таймер и ночные паузы.

---

## 🚀 Деплой на Railway — пошаговая инструкция

### Шаг 1 — Получи Telegram API credentials

1. Открой [my.telegram.org](https://my.telegram.org) и войди своим номером телефона
2. Перейди в **API development tools**
3. Создай приложение (название и описание — любые, платформа — Other)
4. Сохрани `api_id` (число) и `api_hash` (строка) — они нужны на следующих шагах

---

### Шаг 2 — Сгенерируй Session String (делается локально, один раз)

```bash
# Установи зависимости (нужен Python 3.10+)
pip install telethon

# Запусти генератор
python gen_session.py
```

- Введи номер телефона в формате `+79001234567`
- Telegram пришлёт код — введи его
- Если есть 2FA-пароль — введи его тоже
- Получишь длинную строку вида `1BVtsOH4BuzCsVb...` — **это Session String**

**Для аккаунта друга:** пусть друг сам запустит `gen_session.py` у себя и пришлёт тебе только строку результата. Код из SMS он не передаёт — скрипт отработает у него.

---

### Шаг 3 — Загрузи репо на GitHub

```bash
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/fishbot.git
git push -u origin main
```

---

### Шаг 4 — Создай проект в Railway

1. Зайди на [railway.app](https://railway.app) и войди через GitHub
2. Нажми **New Project → Deploy from GitHub repo**
3. Выбери свой репозиторий `fishbot`
4. Railway автоматически начнёт сборку (через nixpacks)

---

### Шаг 5 — Добавь переменные окружения

В Railway: открой проект → вкладка **Variables** → добавь:

| Переменная | Значение |
|---|---|
| `TG_API_ID` | твой api_id (число, например `12345678`) |
| `TG_API_HASH` | твой api_hash (строка) |
| `PORT` | `8000` |

> **Session String вводится через веб-интерфейс**, не через env. Он хранится в БД.

---

### Шаг 6 — Добавь Volume (важно!)

Без Volume база данных сотрётся при каждом рестарте деплоя.

1. В Railway: **New → Database** — нет, не это
2. В настройках сервиса: вкладка **Volumes**
3. **Add Volume**: Mount Path = `/app/data`, размер — по умолчанию
4. Railway перезапустит сервис — данные теперь сохраняются между деплоями

---

### Шаг 7 — Получи URL и открой интерфейс

1. Вкладка **Settings → Networking → Generate Domain**
2. Railway даст тебе URL вида `fishbot-production.up.railway.app`
3. Открой его в браузере — увидишь веб-интерфейс FishBot

---

### Шаг 8 — Добавь аккаунт через интерфейс

1. Нажми **+ Добавить**
2. Введи название (для себя)
3. Вставь Session String из шага 2
4. Укажи чат: `@username` группы или числовой ID (`-1001234567890`)
5. Настрой интервал, разброс и ночную паузу
6. Нажми **Добавить аккаунт** — приложение проверит сессию и запустит воркер

## ⚙️ Настройки аккаунта

| Параметр | Описание |
|---|---|
| **Интервал** | Базовая частота отправки (мин. 10 минут) |
| **Разброс (jitter)** | ±N минут случайного отклонения от базы |
| **Ночная пауза** | Время ОТ и ДО — в этот период аккаунт молчит |
| **Часовой пояс** | Пауза считается по локальному времени аккаунта |

Пример: интервал 12 мин + jitter 3 мин = отправка каждые 9–15 минут.
Пауза 23:30–09:00 = молчит ночью по варшавскому времени.

## 📝 Получить ID группы

Если группа приватная и нет username:
1. Перешли любое сообщение из группы боту [@userinfobot](https://t.me/userinfobot)
2. Он покажет `Chat ID` вида `-1001234567890`
3. Используй это число в поле "Чат"

## 🔁 Локальный запуск (для разработки)

```bash
pip install -r requirements.txt

# Создай .env файл
echo "TG_API_ID=12345" >> .env
echo "TG_API_HASH=abc..." >> .env

# Запуск
python main.py
# → открой http://localhost:8000
```

## Структура файлов

```
fishbot/
├── main.py          # FastAPI приложение + API эндпоинты
├── scheduler.py     # Воркеры для каждого аккаунта (asyncio + Telethon)
├── database.py      # SQLite через aiosqlite
├── gen_session.py   # Генератор Session String (запускать локально)
├── templates/
│   └── index.html   # Веб-интерфейс (всё в одном файле)
├── requirements.txt
├── Procfile
├── railway.toml
└── data/
    └── fishbot.db   # БД (создаётся автоматически, монтируй как Volume)
```
